# World War II in Asia - Interactive E-Learning Application

A multimedia educational application built to teach secondary and college students about key historical events, military strategies, and prominent figures during World War II in Asia (1936–1945).

---

## Project Overview

* **Team:** Hong Chee Hui, Lin Yi, Taha Kerai
* **Platform:** Adobe Animate
* **Deployment:** Standalone / Local Execution

### Objectives
1. Educate users on key military strategies and leadership during WWII in Asia.
2. Provide interactive context on historical events in China, the Philippines, and Burma across four key years: 1936, 1941, 1944, and 1945.
3. Help learners achieve an 80% or higher score on post-module quizzes.

---

## Features

* **Interactive Learning Modules**
  * **Event Maps:** Interactive visual maps tracking territorial changes and timeline progressions.
  * **Leader Profiles:** Detailed summaries of key historical figures involved in the Asian theatre.

* **Gamified Assessment**
  * **Randomized Quiz:** Tests knowledge retention with randomized questions and automated scoring.
  * **"Who Am I?" Game:** Visual trivia mode utilizing silhouette hints to help users identify leaders.

* **Media Controls**
  * Background image slideshows.
  * Dedicated toggle controls for background music and audio effects.

---

## Target Audience

* **Students:** Explores historical events beyond textbook material using interactive visual maps.
* **Educators:** Provides interactive media to supplement classroom history lessons.
* **History Enthusiasts:** Offers a structured breakdown of regional events and military strategies.

---

## Application Structure

1. Main Menu (Audio Toggles, Credits, Module Selection)
2. Learn Module (Year Selection: 1936–1945 | Regions: China, Philippines, Burma)
3. Leader Profiles
4. Game Module ("Who Am I?" Silhouette Trivia & Randomized Quiz)
5. Results Page
